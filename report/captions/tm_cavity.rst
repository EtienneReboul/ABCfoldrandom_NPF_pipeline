Independent check of the OF / Occ / IF call: the substrate pocket of each exported model (the {{ snakemake.config["tm_states"]["n_export"] }} per state of the previous figure, same order: x = alpha to the state's corner, as in the file names) found with pyKVFinder (ChimeraX kvfinder settings, volume cutoff {{ snakemake.config["tm_cavity"]["volume_cutoff"] }} A^3). Pocket = the cavity lined by the most CDD "putative chemical substrate binding pocket" residues (InterPro API, ``data/inputs/<protein>/cdd_sites.json``); without a CDD site, the cavity nearest the transport axis. Bars: area of the pocket's openings to the bulk, placed on the membrane normal of the model (inside -> outside axis between the TM helix-end centroids of each leaflet): extracellular (red, up) when the opening sits more than {{ snakemake.config["tm_cavity"]["side_z"] }} half-membranes above the mid-plane, intracellular (blue, down) below, lateral (grey, a leak towards the lipid) in between; openings under {{ snakemake.config["tm_cavity"]["min_area"] }} A^2 ignored. o = no opening (occluded), x = no pocket (under {{ (snakemake.config["tm_cavity"]["min_cdd_frac"] * 100) | int }} % of the CDD residues line any cavity: collapsed or misfolded site). Pink = the pocket disagrees with the PCA state (OF should be open outside only, Occ closed, IF open inside only).
